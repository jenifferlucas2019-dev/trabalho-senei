# 🦺 Segurança do Trabalho

Um site desenvolvido para promover a conscientização sobre Segurança do Trabalho, apresentando informações, normas, boas práticas e equipamentos de proteção individual (EPIs).

## 📌 Objetivo

O projeto tem como objetivo fornecer informações sobre prevenção de acidentes, saúde ocupacional e a importância do uso correto dos equipamentos de proteção, contribuindo para um ambiente de trabalho mais seguro.

## 🚀 Funcionalidades

- Página inicial responsiva
- Informações sobre Segurança do Trabalho
- Seção sobre Equipamentos de Proteção Individual (EPIs)
- Dicas de prevenção de acidentes
- Layout moderno e intuitivo
- Navegação simples e organizada

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
